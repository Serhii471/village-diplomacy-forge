# Guard assets for the v0.1 integration

Runtime resources: `assets/villagediplomacy/textures/entity/guard/guard_{base,plains,mountain,forest}.png`, each 64×64. These exact bytes come from the pre-garrison `02c4bf0` commit on Serhii's branch. No resident textures or identity palettes are imported.

The server derives the uniform from the home settlement's primary specialization and synchronizes it through entity metadata. Unbound, removed or unassigned settlements use `guard_base.png`. The wide PlayerModel renders skin overlays; ordinary equipment renders through the existing armor layer.

Source/editable material remains on `2nd-test` under `prototypes/guard-skins` with the authoring script `tools/create_guard_skins.cjs`. It is not needed by this runtime package and is not copied into the JAR.

## Provenance and redistribution permission

The earlier source README records that the base skin was supplied by Serhii as `de0fe96cd98e19a0.png`. On 2026-11-24 Serhii confirmed that he has the necessary rights to use and redistribute this base skin in Village Diplomacy. Regional recoloring, trim, collar, belt and insignia were prepared for this project. The guard textures are included with permission for distribution as part of Village Diplomacy; this statement does not grant a separate standalone license to reuse the source skin outside the mod.
