# Village Diplomacy v0.1.0 — встановлення та склад версії

Ця інструкція призначена для звичайних гравців і власників серверів. Для встановлення готового мода не потрібні вихідний код, Gradle або середовище розробки.

## 1. Системні вимоги

- Minecraft Java Edition `1.20.1`.
- Minecraft Forge `1.20.1-47.4.28`.
- Java 17.
- Файл мода `villagediplomacy-0.1.0.jar`.
- Додаткові моди або бібліотеки не потрібні.

Не використовуйте цей JAR із Fabric, NeoForge, Bedrock Edition або іншою версією Minecraft.

### Перевірка завантаженого JAR

Для офіційного release-файлу v0.1.0 очікується SHA-256:

```text
095c4f0063811fe88fdc792cea433319d9fec52d0d3a2ce83d2a0926d8cce8f3
```

Windows PowerShell:

```powershell
(Get-FileHash .\villagediplomacy-0.1.0.jar -Algorithm SHA256).Hash
```

Linux:

```bash
sha256sum villagediplomacy-0.1.0.jar
```

macOS:

```bash
shasum -a 256 villagediplomacy-0.1.0.jar
```

Якщо checksum відрізняється, не запускайте файл: завантажте JAR повторно з офіційного GitHub Release.

## 2. Встановлення для одиночної гри

1. Зробіть резервну копію важливих світів.
2. Встановіть Java 17.
3. Встановіть Forge `1.20.1-47.4.28` як клієнтський профіль.
4. Один раз запустіть профіль Forge і закрийте Minecraft. Це створить потрібні папки.
5. Відкрийте папку `mods` активного профілю:
   - Windows: `%APPDATA%\.minecraft\mods`;
   - Linux: `~/.minecraft/mods`;
   - macOS: `~/Library/Application Support/minecraft/mods`.
6. Скопіюйте до неї офіційний `villagediplomacy-0.1.0.jar`. Не розпаковуйте JAR.
7. Видаліть із цієї папки старі або дубльовані версії Village Diplomacy.
8. Запустіть профіль Forge.
9. У меню **Mods** знайдіть **Village Diplomacy** і перевірте:
   - версія `0.1.0`;
   - автори `Arthur, Serhii`.

Для нового проходження рекомендовано створити окремий світ. Якщо мод додається до наявного світу, обов'язково збережіть його резервну копію.

## 3. Встановлення на dedicated server

1. Зупиніть сервер і створіть резервну копію світу та папки конфігурації.
2. Переконайтеся, що сервер запускається на Java 17.
3. Установіть Forge Server `1.20.1-47.4.28` в окрему серверну папку.
4. Прийміть Minecraft EULA у `eula.txt`, якщо сервер запускається вперше.
5. Скопіюйте `villagediplomacy-0.1.0.jar` у серверну папку `mods`.
6. Встановіть той самий JAR і ту саму версію Forge на кожен клієнт, що підключатиметься.
7. Запустіть сервер штатним Forge-скриптом `run.bat` на Windows або `run.sh` на Linux/macOS.
8. Підключіться клієнтом і перевірте, що немає позначки про несумісні моди або мережевий протокол.

Мод має серверну логіку, тому його наявності лише на клієнті недостатньо. Сервер і всі гравці повинні використовувати сумісну однакову версію.

## 4. Оновлення або перевстановлення

1. Закрийте Minecraft або повністю зупиніть сервер.
2. Зробіть резервну копію світу.
3. Видаліть попередній JAR Village Diplomacy з папки `mods`.
4. Скопіюйте новий JAR; не залишайте дві версії одночасно.
5. Перевірте вимоги нової версії та запустіть гру.
6. Після першого запуску перегляньте `logs/latest.log` на наявність помилок.

Не переносіть світ із версії 0.2.x назад у 0.1.0: дані мешканців і гарнізону не входять до формату v0.1.

## 5. Видалення мода

1. Закрийте гру або сервер.
2. Зробіть резервну копію світу.
3. Видаліть `villagediplomacy-0.1.0.jar` із папки `mods`.

Не відкривайте важливий модифікований світ без мода, якщо плануєте продовжувати його використовувати: блоки, предмети, охоронці та збережені дані Village Diplomacy можуть зникнути або стати недоступними. Найбезпечніший спосіб повернення — відновити резервну копію та потрібний JAR.

## 6. Перші кроки у грі

1. Знайдіть поселення з центральним дзвоном.
2. Створіть **Leadership Seal** і двічі використайте його на дзвоні протягом 10 секунд.
3. Розмістіть **Diplomacy Table** у межах зареєстрованого поселення, не далі ніж за 32 блоки від центрального дзвона.
4. Знайдіть інше поселення та використайте **Diplomatic Scroll** на його дзвоні.
5. Поверніться до дипломатичного столу й перегляньте вкладки поселення, відносин, торгівлі та маршрутів.
6. Приймайте торговельні пропозиції, переносіть звичайні Minecraft-ресурси й передавайте їх представнику поселення біля дзвона.
7. Після розвитку відносин створюйте торговельні договори, дипломатичні союзи й маршрути.
8. Використовуйте **Trade Route Map** і **Route Signpost** для навігації між відомими поселеннями.

Village Guard Spawn Egg доступний лише у творчому режимі й призначений для створення охоронця під час демонстрації або тестування.

## 7. Основні компоненти v0.1

### Поселення та лідерство

- Постійна реєстрація поселення навколо дзвона.
- Один лідер і серверна перевірка його прав.
- Один гравець може очолювати лише одне поселення.
- Збереження даних після виходу, перезапуску світу або сервера.

### Спеціалізації та виробництво

- Рівнинна, гірська, лісова або змішана спеціалізація.
- Аналіз місцевості навколо поселення.
- Денне виробництво профільних ресурсів.
- Віртуальний склад з обмеженою місткістю та прогресом без завантаження чанків.

### Відкриття та дипломатичний стіл

- Відкриття чужих поселень дипломатичним сувоєм.
- Координати, відстань, лідер, спеціалізації, ресурси й відносини.
- Чотири вкладки GUI: поселення, відносини, торгівля та маршрути.

### Торгівля

- Delivery та exchange contracts.
- Перенесення звичайних Minecraft-стаків без запечатаних контейнерів.
- Часткова передача ресурсів зі збереженням прогресу.
- Строки виконання, репутація та штрафи.
- Одноразова винагорода без можливості дублювання.

### Договори, союзи та відносини

- Пропозиція, прийняття, відхилення, відкликання й припинення торговельних договорів.
- Дипломатичні союзи після виконання вимог щодо торгівлі та репутації.
- Ворожі, нейтральні, дружні та союзні відносини з перевіркою на сервері.

### Маршрути

- Постійні торговельні маршрути між відомими поселеннями.
- Trade Route Map зі станом кінцевих точок.
- Route Signpost із напрямком, відстанню, відносинами та станом маршруту.
- Бонуси до винагород за позначений маршрут.

### Охоронці

- Прив'язка охоронця до домашнього поселення.
- Обмежене патрулювання та повернення після переслідування.
- Дипломатичні правила вибору цілей.
- Реакція стандартних ворожих мобів на охоронця.
- Збереження дому й стану після перезапуску.
- Базова, рівнинна, гірська та лісова форма з підтримкою звичайної броні.

### Мови й налаштування

- Англійська та українська локалізації.
- Серверні налаштування спеціалізації, виробництва, місткості складу, тривалості контрактів, репутації та частоти перевірок.

## 8. Що не входить у v0.1

- Людські моделі мешканців.
- Професії та професійні текстури мешканців.
- Набір, навчання й демобілізація.
- Екран і керування гарнізоном.
- Дипломат-NPC, кур'єри, каравани, облоги та автономні події.

Мешканці, професії, recruitment і garrison належать до лінійки 0.2.x та не повинні бути присутні у v0.1 JAR.

## 9. Типові проблеми

### Мод не з'явився в меню Mods

- Переконайтеся, що запускаєте саме Forge-профіль 1.20.1.
- Перевірте, що JAR лежить у папці `mods` активного профілю, а не у вкладеній папці або ZIP-архіві.
- Видаліть дубльовані версії мода.

### Гра або сервер не запускається

- Перевірте `java -version`: потрібна Java 17.
- Переконайтеся, що використовується Forge `47.4.28` для Minecraft 1.20.1.
- Перегляньте `logs/latest.log` і папку `crash-reports`.

### Неможливо підключитися до сервера

- Сервер і клієнт повинні мати однакову версію Village Diplomacy.
- Сервер і клієнт повинні використовувати сумісні версії Minecraft та Forge.
- Видаліть зайві старі JAR із папки `mods`.

### Відсутні текстури або предмети мають неправильний вигляд

- Не використовуйте одночасно кілька версій Village Diplomacy.
- Перевірте, що JAR не було перейменовано на `.zip` або розпаковано.
- Перезапустіть гру після виправлення папки `mods`.

Логи клієнта зазвичай знаходяться в `.minecraft/logs/latest.log`, а логи сервера — у `logs/latest.log` його серверної папки. Для повідомлення про проблему додайте версію Minecraft, Forge, Java, список модів і відповідний лог, але не публікуйте паролі, токени або приватні адреси сервера.
